# 中文文案规范

1. 使用简体中文和全角标点，说清楚用户能做什么。
2. 标题简短直接，不使用“极致、颠覆、赋能、开启命运之旅”等空泛表达。
3. 按钮使用动词，例如“立即排盘、重新填写、复制结果、生成分享文案”。
4. 表单使用中文用户熟悉的名称：出生日期、出生时间、出生地、日历类型、是否闰月。
5. 错误提示说明具体问题和改法，不单独显示 `Error`。
6. 不在用户界面使用 Four Pillars、Ten Gods、Luck Cycle 等英文命理名词。
7. 不恐吓用户，不做绝对判断，不声称可以改变或精准预测命运。
8. 分析内容保持“仅供传统文化研究、娱乐和自我探索参考”的边界。
9. 中文与英文、数字之间适当留空，库名称只出现在技术文档中。
10. 对隐私做真实描述：浏览器记忆与账号数据分开说明，不承诺不存在的本地存储方式。

## 玄枢的口吻

像一个懂传统文化、见过很多真实生活场景、愿意把话讲明白的编辑。语气平静、具体、有分寸，不扮大师，也不假装心理咨询师。

每段解读按这个顺序写：

1. 先说用户在生活里可能遇到的具体表现。
2. 再说明这条判断参考了哪些命盘或星盘信息。
3. 最后只给一个当下能做的小动作。

专业术语可以保留在“查看依据”中，但不能占据首屏结论。首屏优先回答：这和我每天的工作、关系、情绪、选择有什么关系？

## 避免模板腔

不要反复使用这些抽象词：

- 结构化观察
- 当前阶段
- 行动建议
- 环境适配
- 反应路径
- 建立结构关系
- 转换成容易理解的内容
- 维度、模型、参数、模块

这些词不是绝对禁用，但必须换成用户能看到、能感受到的事情。例如：

| 模板腔 | 玄枢写法 |
| --- | --- |
| 你的行动与环境适配 | 你做事的习惯 |
| 当前阶段要抓住主线 | 最近事情来得快，先守住最重要的一件 |
| 正在建立结构关系 | 正在看看这些信息如何互相影响 |
| 转换成容易理解的内容 | 正在整理成一份好读的报告 |
| 土金环境更易发挥 | 规则讲清楚、事情有回音时，你更容易把本事发挥出来 |
| 行动建议 | 今天先做这一件 |

避免连续使用“你不是……而是……”句式。优先直接说事实，例如把“你不是慢热，而是在确认安全感”改成“关系还不确定时，你会先观察；确认对方有回应后，你才愿意投入”。

## 页面写法

- 标题：先给一个明确判断，最多两行。
- 正文：补一个生活场景，不重复标题。
- 标签：写可识别的特点，不写抽象概念。
- 按钮：说明点完会看到什么，例如“看看我们的合盘”。
- 生成页：说系统正在处理哪一步，不写 AI、模型、算法或校准。
- 资料不足：先说明还能看什么，再解释为什么缺少部分结果。
- 登录提示：先说明登录的实际好处，同时保留“先不登录”。
- 免责声明：放在次要位置，表达克制，不打断阅读。
